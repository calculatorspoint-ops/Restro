# RestoSetup ERP - Restaurant Management System

Modern Multi-branch Restaurant Management System built with React, Vite, Tailwind CSS, and Firebase.

---

## 🚀 Live Deployment & Git Sync

This project is configured with automatic GitHub push and Vercel deployment:

- **GitHub Repository**: [calculatorspoint-ops/Restro](https://github.com/calculatorspoint-ops/Restro)
- **Branch**: `master`
- **Hosting**: Vercel

---

## ⚡ How Auto-Push & Deploy Works

1. **Automatic Background Sync**:
   - Run `npm run auto-sync` (or keep the background watcher active).
   - Any time you edit and save files in this project, changes are automatically committed and pushed to GitHub.
   
2. **One-Click Manual Push / Deploy**:
   - Run `npm run deploy` or `npm run push` in the terminal.
   - Or simply double-click `deploy.bat` in the project root folder.

3. **Vercel Automatic Deployment**:
   - Vercel connects directly to your GitHub repository `calculatorspoint-ops/Restro`.
   - Every push to the `master` branch triggers an automated build and deployment on Vercel.
